CLIENTTIME – pirmoji PWA versija

Failai:
- index.html – visa programėlės sąsaja ir funkcijos
- manifest.webmanifest – įdiegimo į telefoną nustatymai
- sw.js – bazinis veikimas neprisijungus (reikia HTTPS)

Paleidimas:
1. Įkelkite visus tris failus į GitHub repository (root katalogą).
2. GitHub: Settings > Pages > Deploy from a branch > main / root.
3. Atidarykite GitHub Pages adresą iPhone Safari.
4. Share > Add to Home Screen.

Pastabos:
- GPS veikia tik HTTPS aplinkoje ir gavus leidimą.
- Nuotraukos, parašas ir įrašai šioje versijoje saugomi lokaliai tame įrenginyje.
- PDF kuriamas per naršyklės spausdinimo langą: pasirinkite Save as PDF.
- iOS foninio laikmačio tikslumas priklauso nuo sistemos; laikas perskaičiuojamas pagal pradžios/pabaigos laiko žymas, todėl sustabdžius programėlę skirtumas perskaičiuojamas teisingai.
- Tai darbo laiko ataskaita, ne pilnai fiskalinė sąskaita faktūra.
